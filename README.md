# Open Game — тренажёр дебютов

Минимальное статическое веб-приложение для заучивания дебютных линий. Вы играете за выбранную сторону
и должны делать книжные ходы; соперник отвечает ходами из базы мастерских партий. Ошибка — тренировка
останавливается, правильный ход показывается стрелкой. Каждый ход сопровождается обоснованием
(можно отключить).

Первый дебют — **Сицилианская защита** за белых и чёрных: Найдорф, Дракон, Свешников, Таймановская
система + служебные ветки (ответы чёрных на анти-сицилианки и ответы белых на побочные системы чёрных).

Второй пресет — **Дебютные ловушки** (`tools/lines/traps.lines.json`): не один дебют, а 10 классических ловушек
за белых (детский мат, мат Легаля, ловушки в Петрове, Каро-Канн, Дамиано, ФГП, Филидоре, голландской, Монтичелли,
Тарраша) и 10 за чёрных (Блэкберн–Шиллинг, Энглунд, Стаффорд, слоновая, Ласкер, сибирская, «Ноев ковчег»,
Кенингер, «Удочка», Мортимер). Каждая ловушка — линия с `side` той стороны, которая её ставит; соперник в неё
попадается.

## Запуск

Сборка не нужна — это чистый ES-модульный JS. Нужен любой статический сервер (из-за `fetch` JSON):

```bash
npm run serve      # http://localhost:5173
# или: python3 -m http.server 5173
```

## Структура

```
index.html, css/, js/          — приложение (app, board, trainer, ui, openings, fen)
vendor/                        — chess.js (правила) и chessground (доска), без CDN
data/openings/index.json       — список дебютов
data/openings/<id>.json        — сгенерированный граф дебюта
tools/lines/<id>.lines.json    — ИСТОЧНИК ПРАВДЫ: варианты в мини-PGN + русские комментарии
tools/build-opening.mjs        — генератор графа + верификация по Lichess Masters DB
tools/cache/                   — кэш ответов explorer (коммитится, сборка воспроизводима без токена)
tools/report/<id>.md           — отчёт: доли ходов в базе, непокрытые популярные ответы
test/                          — node:test
```

## Формат графа дебюта

Узлы ключуются FEN-ом без счётчиков ходов, поэтому транспозиции автоматически сливаются.
У каждого ребра: `san`, `uci`, `to`, `comment`, `lines` (к каким именованным линиям относится ход),
`stats` (партии/доля/результат из базы мастеров).

Линии (`lines[]`): `priority` задаёт порядок «самых удачных» (выбор top-K в настройках),
`side` — за кого линия, `always: true` — служебная линия, включается всегда и не занимает слот
(например, ответы на 2.c3 за чёрных).

`weighting: "lines"` (опционально, на уровне графа) — соперник выбирает ход с весом по числу выбранных линий,
а не по числу партий мастеров. Нужно для ловушек: ошибочные ходы у мастеров почти не встречаются.

Глубина: по умолчанию выбранная линия играется **до конца** — до последнего книжного хода (успех с
причиной `book-end`), в любом дебюте. Слайдер «Глубина» — необязательный ограничитель: крайнее правое
положение («до конца линии») снимает ограничение и стоит по умолчанию, меньшее значение завершает партию
после указанного числа ходов пользователя (успех с причиной `depth`).

Правило тренажёра: для хода **пользователя** книжными считаются ходы выбранных основных линий;
служебные — только если в позиции нет основных ходов (соперник уклонился). **Соперник** может играть
любой ход из основных и служебных линий, с вероятностью по числу партий.

## Пересборка дебюта и верификация по базе Lichess

1. Получите личный токен Lichess (скоупы не нужны): https://lichess.org/account/oauth/token/create
2. `LICHESS_TOKEN=lip_xxx npm run build:openings`

Скрипт проигрывает каждый вариант через chess.js (нелегальный ход = ошибка), запрашивает
`https://explorer.lichess.org/masters` для каждой позиции (с кэшем в `tools/cache/`), сортирует ходы по
популярности и пишет отчёт `tools/report/<id>.md`, где перечислены ходы с долей < 2 % и популярные
(≥ 10 %) ответы, не покрытые графом.

Без токена и кэша граф собирается без статистики (соперник выбирает ходы по числу линий через ход).

**Автодополнение.** В `tools/lines/<id>.lines.json` поле `autoExtend` (`minShare`, `minGames`, `plies`, `maxPly`)
включает достройку графа: для каждой позиции курируемых вариантов популярные ответы соперника, не покрытые
вручную, достраиваются по главной линии базы мастеров и помечаются `auto: true` (без аннотаций — в UI для них
показывается статистика). Отчёт перечисляет их отдельно, чтобы постепенно снабжать комментариями.

`node tools/peek.mjs "1.e4 c5 2.c3 Nf6|6"` — показать топ-ходы базы для позиции и достроить главную линию на 6 полуходов
(удобно при написании вариантов).

## Добавить новый дебют

1. Создать `tools/lines/<id>.lines.json` по образцу сицилианки (поля `lines`, `variations[].pgn`).
2. `npm run build:openings <id>`
3. Добавить запись в `data/openings/index.json`.
